## 加密参数

- 格式：7z（`-t7z`），算法 **AES-256**
- 文件名加密：开启（`-mhe=on`，无密码看不到内部文件名）
- 压缩等级：仅存储（内容本身为 zip，不再二次压缩）
- 分卷大小：95 MB / 卷（`-v95m`，低于 GitHub 单文件 100MB 限制）

## 如何解压

1. 把 `firstpack.7z.001` ～ `firstpack.7z.027` **全部 27 个分卷下载到同一个文件夹**（缺一不可）。
2. 安装 [7-Zip](https://www.7-zip.org/)（或支持 7z 分卷的解压软件）。
3. 右键 `firstpack.7z.001` → 7-Zip → 解压，输入解压密码，即可得到上述 7 个 zip。
4. 命令行：
   ```
   7z x firstpack.7z.001 -p<解压密码>
   ```

> 解压密码不在本公开仓库中，通过私下/线下渠道单独提供。
